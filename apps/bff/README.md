## Description

This API allow the web app consuming and show the characters of a specific episode of Rick and Morty.

## Project setup

```bash
$ yarn install
```

## Compile and run the project

**Development**
```bash
$ yarn run start
```

**Development - Watch mode**
```bash
$ yarn run dev
```

**Production**
```bash
$ yarn run prod
```

## Build the app

```bash
$ yarn run build
```

## Debug

```bash
$ yarn run debug
```

## Run tests

**Unit tests**
```bash
$ yarn run test
```

**Unit tests - Watch mode**
```bash
$ yarn run test:watch
```

**Integration tests**
```bash
$ yarn run test:int
```

**Test coverage**
```bash
$ yarn run test:cov
```

**Test debug**
```bash
$ yarn run test:debug
```

## Lint and format

**Lint**
```bash
$ yarn run lint
```

**Format**
