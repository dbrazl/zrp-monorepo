## Description

This repository is a monorepo for the web and BFF applications. These applications fetch characters from the animated series *Rick and Morty* by episode and display information about them to users.

## Project setup

```bash
$ yarn install
```

## Run the project

**Development**
```bash
$ yarn run dev
```

**Production**
```bash
$ yarn run prod
```

## Build the apps

```bash
$ yarn run build
```

## Run tests

**Unit tests**
```bash
$ yarn run test
```

**Test coverage**
```bash
$ yarn run test:cov
```

## Lint and format apps

**Lint**
```bash
$ yarn run lint
```

**Format**
```bash
$ yarn run format
```
